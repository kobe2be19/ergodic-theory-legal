## Hosting with GitHub Pages

Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, folder: **/docs**. The site appears at `https://kobe2be19.github.io/ergodic-theory-legal/`.

## Editing

Edit the Markdown in `source/` (company details live in `source/vars.json`), then rebuild the pages from the app repository with `python3 legal/tools/build.py`. Keep the effective date current when terms change, and give notice of material changes as the documents describe.
